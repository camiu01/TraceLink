## Audit coverage and boundaries

- **Ownership/concurrency:** buses are initialized before tasks; afterwards acquisition
  owns mutable drivers. HTTP/USB share Arduino loop, so static snapshot storage is
  not concurrently reused there. State snapshots/queue/history use one mutex; USB
  output uses another after releasing state. No reverse nested lock order was found
  in inspected paths. This is inspection, not proof under FreeRTOS scheduling.
- **Queue semantics:** single pending command and busy flag gate admission. 202 is
  queue acceptance; shared status has no per-operation completion ID. Busy/scanning
  also reject disarm. No new emergency-stop semantics were introduced.
- **Parsing:** actual callers limit HEX to 64/8 bytes; unsigned arithmetic checks
  overflow; serial text length is bytes. Shared validation rejects embedded NUL.
  USB bounds 1024 bytes, validates request CRC/ID, discards stale/invalid lines
  through LF and rejects duplicate/unknown form keys. Native tests cover these
  paths and wraparound; HTTP duplicates are not validated like USB forms.
- **History:** mutex-protected sequence assignment, 32-record API pages, oldest-record
  loss accounting and per-reader cursors were checked. MCP tests verify last-returned
  cursor rather than latest, reboot reset and overwrites. UART driver overflow
  remains uncounted; scan/reconfiguration can reset CAN counters.
- **CAN:** listen-only boot/search and `ss=1` are in source. Normal-mode ACKs and
  queue-versus-delivery limits remain documented. No CAN FD or delivery guarantee.
  Bus-off recovery, physical ACKs and return-to-listen-only require bench evidence.
- **MCP:** named serial selection is lazy/exclusive; URL+serial conflict is rejected,
  HTTP is the documented default when no serial port is configured. No port scan,
  automatic reconnect/fallback/control retry was found. Tests cover disconnect,
  uncertain writes, stale reply IDs, bounds and close cleanup. Actual human
  approval is a client responsibility, not `confirm:true`.
- **Dashboard:** actual script exercised in Node and isolated Chromium with simulated
  APIs. Text-only rendering and CSV formula/quote protection held in tested cases.
  Status updates while paused; records continue updating while rendering is paused,
  so filtered export is not a frozen-table snapshot. Poll failures disable controls;
  reboot resets cursor/token; 403 is not retried as a command.
- **Hygiene:** tracked-file inventory shows no `.pio`, node_modules, `.env` or
  `local_config.h` artifacts. A pre-existing modification remains in tracked
  `include/config.h`; it must not be staged inadvertently. Existing `.factory/`
  and `security-findings.json` were left untouched. No exhaustive secret-history
  scan or external dependency vulnerability assessment was performed.
